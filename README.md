### Тестирование формы обратной связи



В рамках учебного проекта выполнен анализ и тестирование формы обратной связи веб-приложения.



Выполненные работы:



\- Декомпозиция интерфейса: проанализированы элементы формы обратной связи, выполнена декомпозиция заголовка, подзаголовка, поля Email и кнопки «Отправить».

\- Анализ классов эквивалентности и граничных значений: дополнена таблица проверок для полей «Имя», Email, «Телефон» и «Сообщение». Определены недостающие классы эквивалентности и граничные значения для проверки корректности ввода данных.

\- Разработка тест-кейсов: составлены недостающие тест-кейсы для проверки вёрстки и логики работы формы. Подготовлены проверки отображения элементов интерфейса, валидации полей и обработки пользовательского ввода.

\- Ручное тестирование: выполнены проверки формы обратной связи на тестируемой реализации в соответствии с составленными тест-кейсами.

\- Документирование дефектов: выявленные ошибки зафиксированы в баг-репортах с описанием обнаруженных проблем.



**Применённые навыки и техники:** декомпозиция интерфейса, тест-дизайн, классы эквивалентности, анализ граничных значений, составление тест-кейсов, ручное функциональное тестирование и оформление баг-репортов.
